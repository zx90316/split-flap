# 1～10 位顯示與啟用位置

同一份Mega韌體接受 `DIGITS 1` 到 `DIGITS 10` 的任一位數，不需重新編譯。每位仍是原版45片字元，腳位沿用[U0～U9表](README.md#十字元腳位與-4p-方向)。開機預設只啟用U0、所有馬達關閉，參數與安裝配置只存RAM。

## 目前完成到哪裡

| 1～10任意位數、非連續啟用位置 | 已實作；未啟用的馬達輸出保持LOW |

這是可用的USB多位調機與文字顯示韌體，完整產品功能仍有上表待辦。

## 為何不能自動知道有沒有接

目前Mega到ULN只有四路相位控制，沒有連接偵測或電流回報；[TI資料表的腳位表](https://www.ti.com/lit/ds/symlink/uln2003a.pdf)列出邏輯輸入、集極輸出、COM與E。依本專案接線，Mega無法從ULN確認馬達是否插上。Hall未觸發時的HIGH也不能證明馬達存在；目前更沒有磁鐵可用來核對轉動。

因此，**只把實際接上的組別列入DIGITS／UNITS**。若誤啟用未接的組別，韌體仍會輸出預定步數；手動定位與DONE都不能當作硬體存在回報。本版不會自動試轉未啟用位置。

## 選擇任意位數

| 指令 | 啟用位置 |
| --- | --- |
| `DIGITS 1` | U0 |
| `DIGITS 3` | U0、U1、U2 |
| `DIGITS 5` | U0～U4 |
| `DIGITS 7` | U0～U6 |
| `DIGITS 10` | U0～U9 |
| `UNITS 0,2,7` | 三位，文字第1／2／3字分別對應U0／U2／U7 |
| `UNITS 9,0,4` | 三位，依輸入順序對應U9／U0／U4 |

DIGITS接受1～10所有整數；0、11、重複ID、空清單與無效ID會被拒絕，保留原配置。UNITS用逗號分隔，不加空格。改配置會解除全部ARM並使全部位置失效，但保留各U的校準參數；選中位置若被停用，會改選清單第一位。

`UNIT n` 只選擇已啟用的實體U編號，保留各位狀態。停用的組別不能用UNIT選取，也不會參與TEXT、ARM ALL、HOME ALL、CYCLE ALL或全組調速。十位BOM與接線是最大容量規劃；N位使用N顆馬達／ULN／機構、45×N片翻頁片，電源與線材依實際負載確認。

## 沒有磁鐵：宣告目前文字再顯示目標

先依單顆流程逐一確認每組能平順向前翻頁。下面假設已接U0～U4，眼前從左到右**實際顯示ABCDE**。每行分別送出並等回覆；TEXT等DONE再送下一行：

```text
DIGITS 5
SETTEXT ABCDE
ARM ALL
TEXT HELLO
```

SETTEXT不轉動馬達，會將每個實際字元記為手動位置並解除ARM；必須恰好提供DIGITS個字元。ARM ALL只授權輸出，TEXT才會開始逐顆移動。接著可以直接送 `TEXT WORLD`，會依每位最新位置前進，跨圈不尋找霍爾；`STATUS ALL`會列出安裝配置及所有啟用位置的狀態。

文字每位一個ASCII字元，數字0表示實際數字0；空白可用 `_` 或文字內的空格。特殊三格用 `$`／`&`／`#` 表示Ä／Ö／Ü；在單位SET／SHOW則仍可用AE／OE／UE。輸入字母自動轉大寫。

| 例子（五位） | 意義 |
| --- | --- |
| `SETTEXT _____` | 只在五位目前實際全是空白時，用來宣告目前位置 |
| `TEXT HI` | 目標HI，後三位補空白 |
| `TEXT A_B_0` | A、空白、B、空白、數字0 |
| `TEXT " A B "` | 引號保留開頭／結尾空白；中間仍是一位一字元 |
| `TEXT` 或 `TEXT ""` | 目標全部空白 |
| `TEXT HELLO!` | 超出五位，整行拒絕，所有位置都不開始移動 |

不支援的字元、過長文字、SETTEXT長度錯誤都會在任何位開始前拒絕。TEXT也會先檢查全部啟用位置已ARM且位置已知；缺任一條件就全部不啟動。與目標相同的位會略過；整串已相同會立即回DONE。

## 個別與整組操作

| 指令 | 作用範圍 |
| --- | --- |
| `STATUS`／`STATUS ALL` | 選中U／所有啟用U |
| `SET`、`SHOW`、`SETINDEX`、`FLAP`、`GOTO`、`STEP`、`REV`、`LED`、`MEASURE`、`WATCH` | 選中U |
| `ARM`／`ARM ALL` | 選中U／所有啟用U，不會自行轉動 |
| `HOME`／`HOME ALL` | 選中U／依安裝順序逐顆霍爾歸零；沒有磁鐵時先不用 |
| `CYCLE`／`CYCLE ALL` | 選中U／逐顆完整循環；各位需已建立位置並ARM |
| `SPEED 800`／`ACCEL 800` | 選中U |
| `SPEED ALL 800`／`ACCEL ALL 800` | 所有啟用U，會解除這些U的ARM並使位置失效 |
| `ORDER`、`DIR`、`REVSTEPS`、`OFFSET`、`POLARITY` | 選中U，校準各自保留 |
| `STOP`／`OFF`、動作中的任何非換行輸入 | 全部停止、取消尚未開始的位、解除全部ARM與位置 |

U0已回報穩定的800／800不代表其餘馬達已通過相同速度。新增位置先用預設SPEED 5000／ACCEL 400逐顆測試，再按各位結果調整。整組調速後，重新SETTEXT實際目前文字、ARM ALL再TEXT；若部分位已裝磁鐵並完成校準，也可ARM ALL後HOME ALL。

批次中任一位發生Hall故障、迴圈停滯或逾時，會回報FAULT U編號與原因、立即關閉全部輸出，並取消後續排程。重新SETTEXT時要填當下實際文字，因為之前可能只更新了一部分。STOP仍須配合實體12V切斷；批次逐顆運行不代表電源與接線已完成驗收。

本版只做軟體測試與編譯，1～10位實機仍待使用者接線驗證；保留的U0單顆通過紀錄見[驗證紀錄](validation.md)。
