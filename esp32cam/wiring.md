# Mega2560 Pro＋NodeMCU ESP-32S 接線表

適用 2026-10-26 新購的 **Mega2560 Pro CH340G（焊好排針）與 NodeMCU ESP-32S**。功能圖按腳位名稱畫線，不代表實體排針排列、接頭外觀或尺寸。新板尚待到貨核對；原標準 Mega／ESP32-CAM 的排針位置不能直接套用。

## 正常供電：12V 與 5V 共地

![正常配線](wiring-runtime.svg)

| 從 | 接到 | 核對事項 |
| --- | --- | --- |
| 隔離式 12V 電源正端 | F1 保險絲／總開關後分兩支路 | F1 靠近輸入口；額定依負載與最弱導線選定 |
| 控制支路 12V | LM2596 IN+ | 在馬達開關之前分出，馬達關閉時控制板仍有電 |
| 馬達支路 12V | 符合 DC 負載的手動開關→馬達分配→各 ULN +／COM | DIP 不作此開關；12V 不接主控、Hall 或 GPIO |
| LM2596 OUT+ | 調至 5.0V→F2→5V 控制分配 | 空載、接負載後均量電壓；不能只看 LED 亮度 |
| 5V 控制分配 | Mega Pro 5V 輸入、NodeMCU 已確認的 5V 輸入、Hall +、P011 VCCB | 不接任何 3V3 腳；NodeMCU 若印 VIN 先核對電源路徑再接 |
| 電源負端、LM2596 IN−／OUT− | GND 分配母線 | 兩種電壓共地；+12V、+5V、GND 各自獨立母線 |
| 兩塊主控、P011、Hall GND | GND 分配母線 | 不依 USB 外殼當唯一地線 |
| 各 ULN GND | 直接回 GND 分配點 | 馬達回流不穿過 Mega／ESP32／Hall 細線 |

兩板正常外部供電時，電腦 USB 拔除。NodeMCU 的 5V／VIN 名稱與電源路徑可能因相容板不同；到貨先核對，**不把 12V 送入兩塊主控**。LM2596 IC 的標稱 3A 不等於任意小模組可連續承受 3A，仍需量負載電流、壓降與溫升。

已購兩個「中號18號線(5A)」保險絲座；是否附保險絲到貨確認，**不預設 F1／F2 都用 5A**。四個 KF301 2P 需焊接到板子及分配導線，並非十路完成配電板。0.5mm 單芯線是直徑、約 0.196mm²，只作短訊號／驗證後單組支路，不作馬達總線。高溫膠帶輔助絕緣，仍需固定柱及線材應力消除。

## UART：沿用 P011 的兩路

| 從 | 接到 | 用途 |
| --- | --- | --- |
| NodeMCU GPIO13 TX2 | P011 A0 | ESP32→Mega 的 3.3V 側 |
| P011 B0 | Mega Pro D19 RX1 | 同一路的 5V 側 |
| Mega Pro D18 TX1 | P011 B1 | Mega→ESP32 的 5V 側 |
| P011 A1 | NodeMCU GPIO14 RX2 | 同一路的 3.3V 側 |
| NodeMCU 3V3 | P011 VCCA | 3.3V 參考電源 |
| Mega Pro 5V 電源節點 | P011 VCCB | 跟 Mega 同一電源域 |
| P011 GND | 共地 | VCCA／VCCB 重複端子按實板擇一 |
| P011 A2～A7／B2～B7 | 留空 | 不串接、不短接、不接地 |

**A0↔B0、A1↔B1 是兩組獨立通道；B0 與 B1 不短接。** GPIO13／14 是晶片邏輯腳號，不是從排針第一根數第13／14根。UART 為 115200、8N1；兩板各自的 USB 串列也是 115200，板間訊號不接 USB UART0。

P011 沒有 OE，不假設單側斷電隔離。切換任一板供電前，先關電並拔 A0／A1／B0／B1 四條訊號線，避免回灌。原八路板曾在舊硬體通過短線 115200 測試；新板與馬達干擾、長線仍須重驗。[同類 MOS 轉換板原理參考](https://www.adafruit.com/product/757)不等於本板型號或速率認證。

| U0 | D22／D24／D26／D28 | A0 |
| U1 | D30／D32／D34／D36 | A1 |
| U2 | D38／D40／D42／D44 | A2 |
| U3 | D46／D48／D50／D52 | A3 |

Hall + 接 5V、− 接 GND，S／+／− 針序依實板核對。[Hall 洞洞板](../mega2560/hall-board.svg)僅負責 Hall 訊號與供電分線；不承擔馬達電流。

Pro 若為已焊公排針，ULN 端也是公針時用母母線；四條相位線按邏輯腳個別對接，不保證四個腳在 Pro 上連續。標準 Mega 的母排則需公頭。D0／D1 留給 USB，D18／D19 留給板間 UART，D20／D21 暫預留，不新增 DIP 或繼電器接線。

## USB 燒錄與供電切換

![兩板各自 USB](wiring-flashing.svg)

兩塊板都自帶 USB-UART，**不使用外接 CP2102**；USB 插頭與驅動依到貨實板核對。

1. 關閉馬達與 LM2596 控制電源，拔板間四條 UART 訊號線。
2. **拔掉要接電腦那塊板的外部 5V 線**，確認沒有其他外部 5V 接入，再用板上 USB 資料線接電腦。只關馬達支路不能達到供電隔離。
3. 重新查詢 COM；F5 選 `MEGA: 建置＋燒錄＋串列除錯` 或 `ESP32-S: 建置＋燒錄＋串列監看`。新板 COM 不一定是舊 COM3／COM4。
4. NodeMCU 通常自動重設進入下載；停在 Connecting 時按住 BOOT、按一下 EN／RESET，開始寫入再放開 BOOT。完成後若未啟動，按 EN／RESET。無需 GPIO0 跳線。
5. 完成後結束監看、拔電腦 USB，確認控制電源仍關閉，再復原該板外部 5V 與四條 UART 訊號線。全部共地、兩板都供電後，以 ESP32 `STATUS` 確認 `Mega=connected`。
6. 搬移舊 Mega 校準／設定，核對實物重新定位，再 ARM，最後開馬達支路測 U0。新 EEPROM／NVS 不含舊板資料，詳見[搬移紀錄](../hardware/purchased-2026-10-26.md#到貨與設定搬移)。

可以只燒錄一塊板，另一板維持斷電與訊號分離。沒有確認電源隔離電路前，兩板都採外部 5V 與電腦 USB 互斥；不用 USB Y 型線或兩路正極並接。板上 USB-UART 只提供燒錄與串列紀錄，現有 F5 主機中斷點屬模擬核心，不是實板硬體單步除錯。

## DIP 與繼電器

使用者允許 DIP 作其他設定用途，但沒有確認其接點額定，因此目前登錄為備用低電流設定零件，**不放 12V 馬達總線、不接 GPIO**；位數仍由網頁 DIGITS／UNITS 管理。

依使用者選擇，SRD-12VDC-SL-C 繼電器保持選配。控制側供電／IN 觸發與上拉電壓未確認，本版不驅動、不接 IN。未來若整合，馬達側用 COM／NO，保留保險絲及合適的手動馬達開關；10A 外殼標示不能直接當作本模組的馬達負載額定。

正常開機不 ARM，位置必須重新確認。軟體 STOP 只關閉相位輸出；本版沒有把 12V 馬達支路自動切斷，實體開關需保持可及。
