近期工作

安裝配置

只列出實際接上的組別，無自動插拔偵測。套用配置會解除全部定位與啟用。

每位校準

整份校準一次驗證並保存；完成後所有位置須重新定位。未啟用位置不會因保存而轉動。

設定備份

備份包含安裝、校準與顯示偏好，不含位置、馬達啟用狀態及 Wi-Fi／登入密碼。

網路與登入

ESP32 可在未連接 Mega 時設定網路；執行工作或更新期間請先停止或等待完成。修改後自動顯示會暫停。更改直連密碼後需重新連 Wi-Fi；更改登入密碼後需重新登入。忘記密碼可用 CP2102 串列輸入 ACCESS，或 NETWORK RESET 重設網路。

ESP32-CAM UPDATE

透過網頁更新 ESP32

先準備更新，等待 Mega 確認停止，再選擇 VS Code 建置輸出的 .sffw 檔案。

更新後設備會重新啟動，請重新定位並啟用馬達。

此功能更新 ESP32-CAM；Mega 使用電腦 USB 燒錄。檔案含板型、協定與 SHA-256 校驗。中斷上傳可重新準備。

第一次燒錄

在 VS Code 執行「ESP32-CAM: 建置＋燒錄＋串列監看」。CP2102 的 TXD 接 U0R、RXD 接 U0T、GND 共地；供電由 LM2596 提供。GPIO0 接 GND 後重設進入燒錄，完成後移除跳線再重設。

完整供電、電平轉換與接線圖見 repo 的 esp32cam 說明。操作實體燒錄前關閉馬達 12V 分支，保留控制電源。
