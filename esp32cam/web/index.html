完整接線圖

單主控：NodeMCU ESP-32S 經電位轉換板驅動四片 MCP23017，不接 Mega。圖檔內建在設備；點圖開原尺寸，依模組印字接線。

P011 曾冒煙：先檢查或更換，且須為 MOS 雙向轉換板。12V 只進 ULN2003；MCP、霍爾、轉換板 B 側都在 5V。

完整接線：電源、ESP32、轉換板、四片 MCP
逐腳對照：GPA／GPB → ULN IN1–4、霍爾、模組排針

現行硬體為 Mega2560 Pro＋NodeMCU ESP-32S。圖檔內建在設備，不需上網。點圖可開啟原尺寸；按板上印字接線，不按方塊位置猜腳位。

現有 8 路板：VCCA 接 ESP 3V3、VCCB 接 Mega 5V。正常運作 B0／B1 不短接。任一板接電腦 USB 前先拔該板外部 5V 與四條 UART 訊號線。新 Mega Pro 的排針位置與標準 Mega 不同，依腳位印字接線。

新購 0.5mm 單芯線是銅芯直徑，約 0.196mm²；不作馬達總電源線。KF301 需焊接分配線，DIP 開關暫不接。保險絲安培數依負載與線材選定。

正常運作：12V／5V、NodeMCU ESP-32S、Mega Pro 與現有 8 路板
兩板各自使用板上 USB 燒錄
U0～U9：Mega、ULN2003、12V 馬達與霍爾
