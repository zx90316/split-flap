# 組裝、校準與驗證

本版完成文件及軟體層的規劃／檢查，尚未完成實物供電與運轉驗證。組裝時按下列順序逐項記錄，沒有證據的格子留空。

機構依 JonnyBooker 固定參考版核對，其組裝 PDF 與本倉庫保留版 SHA-256 相同；[比對與模型來源](upstream-reference.md)。

先讀 [架構與安全限制](architecture.md) 及 [接線表](wiring.md)。上游 [組裝 PDF](../../Instructions/SplitFlapInstructions.pdf) 的機構頁可沿用，但其 Nano、ESP-01、客製 PCB、L7805 與串接電路不屬於本版。

## A. 元件與規格檢查

1. 依 [project-bom.csv](../../hardware/project-bom.csv) 的 item_id 與標準數量準備元件，逐件核對型號、版本、焊接及完整性。
2. `required_quantity` 是十字元基準的組建數量；空白表示須依佈線或實際固定方式確定，並非不需要。
3. `quantity_basis` 區分電氣設計、上游機構參考與依佈局決定的需求。機構參考數量不可取代實際孔位／尺寸檢查。
4. [optional-parts.csv](../../hardware/optional-parts.csv) 的零件不是基準必裝件。選用替代接頭或 PD/QC 輸入時須先驗證相容性。
5. CSV 使用 UTF-8 BOM；以 Python 讀取時使用 `utf-8-sig`。記錄實物版本、額定值與測量結果，以便重現。

## B. 機構保留與試裝

### 印製件與翻頁

- 上游列有各 10 個 FlapDrumInner、FlapDrumOuter、FrameUnit；中框、前蓋、後蓋各左中右三件。3D 檔位於上游連結的 [Split-Flap Display 模型](https://www.prusaprinters.org/prints/69464-split-flap-display)，不在本次修改中重新設計尺寸。
- 每字元 45 片，十字元合計 450 片。先印幾片及一套滾筒／FrameUnit 試裝，檢查翻落、翹曲、摩擦與字面對齊，再批量印。
- 上游有兩種第 27–29 字元：Ä/Ö/Ü 或 $/&/#。整套機構與韌體字元表需一致，不混用半套。
- 將滾筒兩半的起始圓點對齊，從「一面空白、另一面 A 的下半部」的起始片依序裝入。詳細圖示見上游 PDF 第 13–14 頁。

### 磁鐵、Hall 與熱熔螺母

- 上游要求每字元一顆 2×1mm 圓片釹磁鐵，共 10 顆。磁鐵為標準 BOM 的必要零件。
- 先量測實際元件 KY-003 是否為非鎖存輸出、針序與有效磁極。在 5V 單板測試成功後標記磁極，再固定到 FlapDrumInner，避免黏上後無法感測。
- P005 的 PCB 外形、螺絲孔、感測器位置可能與上游不同。試裝時先保持磁鐵與 Hall 相對位置；若要轉接支架，另行量測確認後再做，不盲改整體框架。
- P012 M3 熱熔螺母為 Ø4.6×L5.8mm；P020 M2 為 Ø3.59×L3.94mm。先量孔徑、孔深、周圍壁厚與螺絲伸入長度。名稱同為 M2/M3 不代表外徑和長度適配。
- 在同材料試件測試埋入，依材料／嵌件要求調整溫度和操作，維持垂直且不穿底。不要把上游示例的烙鐵溫度直接當成實際元件材料的唯一設定。

### 電源、保護與安裝需求

穩壓 12V 電源、合格主電源線／端子、保險絲與座、主電源開關、獨立馬達電源切斷開關、模組固定／絕緣件、必要上拉和去耦元件均列入組建需求。電源插座與外殼孔位要實測，不能僅以 5.5mm 名稱判定可鎖入原孔。使用 PD/QC 觸發線時須配套支援 12V 的電源並完成協商測試。

## C. 逐關通電

所有測試都有人看守，馬達分支開關放在伸手可及處。使用合適限流、保險絲與測量工具；只操作隔離後的低壓直流，不拆改市電供應器。每關不通過就停在該關，不同時加接其他模組。

### C1. 電源單獨驗證

- 控制板與馬達全部不接。記錄電源銘牌、可用直流電壓／電流、線材額定值與 DC 極性。
- 若選用 PD/QC 輸入，將觸發線設定 12V，量測空載／適當測試負載電壓，拔插電源驗證設定記憶與重新協商；確認不會誤成更高電壓。
- 查標準 P006 或選配 P003 尺寸、接點、電流額定值與機械固定，決定使用路徑。不同中心孔徑接觸不可靠就停止。
- 單片 P007 接入 12V，先驗 5V 空載，接可控測試負載後驗壓降、紋波與溫升。量測點包含電源端與遠端，不只量模組輸出端。
- 先規劃與驗證馬達分支切斷、接地、線規、保險絲選擇；不以保險絲取代正確接線及切斷開關。

### C2. ESP32 與單片 MCP

- 確認 P008 的 5V 輸入與 USB 路徑。初次燒錄保持外部 5V 和馬達電源斷開，不同時供電。
- 按已確認的供電方式啟動 ESP32，只接一片 MCP、P011 的三路訊號與共用地。
- 在馬達分支關閉下驗證 /RESET 的低脈衝、釋放高電位，I²C 以 100kHz 掃描。確認地址焊橋與軟體一致。
- 單片階段只用 `SCAN POWER_OFF` 掃描；新韌體的完整初始化必須四片都在。加入其餘三片，逐片確認 0x20–0x23，再用 `INIT POWER_OFF` 驗暫存器讀回與輸出低。不能同位址直接並接後猜哪片有回應。
- `SCAN POWER_OFF` 會脈衝重設、掃描 0x20–0x27，結束後保持 /RESET 低，解除 ARM 並使位置失效。掃描成功不等於完成初始化；操作前仍需四片齊備的 `INIT POWER_OFF`。

### C3. 一片 Hall 與一顆馬達

- 馬達電仍關閉，驗單 Hall 的接腳、供電、有效電位與磁鐵離開後恢復，讀值應只改變指定通道。
- 完成 P001 全部導通／相位映射、馬達電阻檢查及 COM 接線紀錄。確認所有驅動輸入低，再允許馬達分支接通。
- 先讓單顆馬達在不帶滾筒的固定狀態低速短暫運轉，確認方向、相序、電流、異音與溫度。運轉後清零全部相位，確認電流確實下降。
- 組上已能手動順暢轉動的滾筒再做單字元歸零。若抖動、卡住或電源重啟，立即切斷馬達電，不提高電壓硬推。

### C4. 逐字元校準

1. 對每顆記錄採用全步或半步、相位順序與機械可用轉向。原全步 2038 只作上游參考；實際元件實際值另量。
2. 記錄 Hall 有效電位、接近／離開邊緣及磁極。若一開始已在有效區，先安全離開，再找同一方向的穩定有效邊緣。
3. 設定合理最大步數與實際時間上限，確認拔掉 Hall 或永遠有效／無效時會報錯停止排程，不會無限轉動。
4. 歸零邊緣後調整到空白頁，將該字元偏移記入設定。偏移單位必須與韌體的全步／半步一致。
5. 在多圈同方向移動中測量相鄰同一 Hall 邊緣的步數，估計每圈步數及重複性。齒比、磁滯、間隙及漏步都可能影響結果；不能把一次測到的整數當精確齒比。
6. 依序走完 45 個字元，檢查對齊與跨圈後誤差，調整每圈步數與空白偏移。本版沒有 45 點獨立位置表；若個別槽位仍有系統性誤差，先查印製件與卡片再評估擴充。記錄目前 100ms 停止保持後是否滑動、溫度是否適當；後續修改保持時間須重測。

### C5. 擴充到十字元與故障測試

- 先 1 顆，再逐步提高同時運轉數。每一級測 12V/5V/3.3V 最低電壓、平均／峰值電流、線材接點和驅動溫度。
- 組裝全部字元後測全部 45 字元、跨圈、反覆歸零、反覆啟停與預期最長連續工作情境。現在以序列控制驗證；Wi-Fi／網頁尚未移植，未來啟用無線功能時須追加無線活動負載測試。測試時長、環境與結果都記錄，不預填通過。
- 控制分支通電、馬達分支切斷時，驗證 ESP32 暖重啟、MCP reset、I²C NACK／線路故障處理。不要帶電拔線製造錯誤，先斷電設置測試接線再測。
- 檢查 brownout 後狀態不再可信，必須重新初始化與歸零。禁止 disable brownout detector 來掩蓋供電問題。
- 在受控單馬達條件確認實體切斷有效。不得以「STOP 指令有回應」代替真的切斷線圈供電。
- 未完成獨立安全互鎖與故障驗證前，不安排無人值守運轉。
